# การทดสอบและผลลัพธ์

## แผนการทดสอบ

| ลำดับ | รายการทดสอบ | ผลที่คาดหวัง | ผล |
| :--- | :--- | :--- | :--- |
| 1 | รัน `main.py` กับคลิป | ตรวจจับรถและส่ง payload ทุก 10 วินาที | ผ่าน |
| 2 | ดักฟัง MQTT ที่ broker | เห็นข้อความจริงบน topic | ผ่าน |
| 3 | Query InfluxDB | พบ `traffic_6620301002` ครบ 7 field | ผ่าน |
| 4 | ตรวจ Kafka topic | พบ message ใน `traffic-events-6620301002` | ผ่าน |
| 5 | รัน `predict_consumer.py` | เขียนค่าพยากรณ์หลังสะสมข้อมูลครบ 5 นาที | ผ่าน |
| 6 | เทียบความแม่นกับเส้นฐาน | MAE ต่ำกว่าการเดาว่าเท่ากับค่าปัจจุบัน | ผ่าน |
| 7 | เปิด Grafana Dashboard | ทุก panel แสดงค่าล่าสุดและกราฟย้อนหลัง | ผ่าน |

## ผลการทดสอบแบบ End to End

```
main.py → Mosquitto → Telegraf ─┬→ InfluxDB → Grafana
                                └→ Kafka → predict_consumer.py → InfluxDB → Grafana
```

| รายการ | ผลที่วัดได้ |
| :--- | :--- |
| ความละเอียดและอัตราเฟรม | 1444 x 1184 ที่ 27 fps บน Apple Silicon (MPS) |
| ระยะห่างระหว่างจุดข้อมูล | 10 วินาที 779 จาก 883 ช่วง คิดเป็น 88% |
| ตัวอย่างข้อมูลที่เข้า InfluxDB | `congestion_level` 3, `vehicles_in_roi` 19, `slow_vehicle_ratio` 0.8 |
| ค่าพยากรณ์ที่เขียนกลับ | `forecast=1.533` สำหรับเวลาอีก 5 นาทีข้างหน้า |

## ความแม่นของโมเดล

| :--- | :--- |

| เดาว่าอีก 5 นาทีเท่ากับตอนนี้ | 0.730 |
