## ผลการทดสอบแบบ End to End

เส้นทางข้อมูลที่ทดสอบสำเร็จ

```
main.py → Mosquitto → Telegraf ─┬→ InfluxDB → Grafana
                                └→ Kafka → predict_consumer.py → InfluxDB → Grafana
```

ตัวเลขที่วัดได้จริงระหว่างทดสอบ

| รายการ | ผลที่วัดได้ |
| :--- | :--- |
| ความละเอียดและอัตราเฟรม | 1444 x 1184 ที่ 27 fps |
| อุปกรณ์ประมวลผล | Apple Silicon ผ่าน PyTorch MPS |
| payload ที่ส่งในรอบทดสอบ | 50 ก้อน |
| ระยะห่างระหว่างจุดข้อมูล | 10 วินาที 779 จาก 883 ช่วง คิดเป็น 88% |
| ช่วงที่เหลือ | 9 หรือ 11 วินาที 50 ช่วง จากการนับเป็นเฟรม และ 4-7 วินาที 43 ช่วง จากการรันแบบ `--no-show` |
| ตัวอย่างข้อมูลที่เข้า InfluxDB | `congestion_level` 3, `vehicles_in_roi` 19, `slow_vehicle_ratio` 0.8 |
| ค่าพยากรณ์ที่เขียนกลับ | `forecast=1.533` สำหรับเวลาอีก 5 นาทีข้างหน้า |

## ความสอดคล้องของสีบนแดชบอร์ด

ทดสอบว่าการไล่สีตามจำนวนรถตรงกับระดับความติดขัดหรือไม่ จากข้อมูลจริง 896 จุด

| ชุดเส้นแบ่ง | ตรงกับระดับจริง |
| :--- | :--- |
| แบ่งเท่า ๆ กัน `[0-7] [8-10] [11-14] [15-20]` | 46% |
| ชุดที่ดีที่สุดเท่าที่เป็นไปได้ `[0-10] [11-12] [13] [14+]` | 73% |

สรุปว่าไม่มีชุดเส้นแบ่งใดที่ทำให้สีตามจำนวนรถตรงกับระดับได้ จึงใช้สีไฟจราจรกับระดับเท่านั้น
