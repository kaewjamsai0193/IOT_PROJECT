# ภาคผนวก

## ภาคผนวก ก คำสั่งเริ่มระบบ

```bash
cd ~/Documents/IOT/IOT_PROJECT

docker compose up -d                        # Mosquitto + Telegraf
.venv/bin/python main.py longvideo.mov      # ตัวตรวจจับ
.venv/bin/python predict_consumer.py        # สาย ML อีกเทอร์มินัลหนึ่ง
```

ถ้าแก้ `telegraf.conf` ต้องสั่งรีสตาร์ตเอง เพราะไฟล์ถูก mount เป็น volume

```bash
docker compose restart telegraf
```

เทรนโมเดลใหม่เมื่อมีข้อมูลสะสมมากขึ้น

```bash
.venv/bin/python train_model.py
```

## ภาคผนวก ข จุดตรวจสอบบริการ

| บริการ | ที่อยู่หรือคำสั่งตรวจสอบ |
| :--- | :--- |
| Mosquitto | `docker compose exec mosquitto mosquitto_sub -t 'traffic/6620301002' -v` |
| Telegraf | `docker compose logs -f telegraf` |
| Telegraf แบบไม่เขียนปลายทาง | `docker compose exec telegraf telegraf --config /etc/telegraf/telegraf.conf --test` |
| Kafka Broker | `172.16.2.117:9092` |
| Kafka UI | http://172.16.2.117:8080 |
| InfluxDB | http://172.16.2.117:8086 |
| Grafana | เครื่องเดียวกับ InfluxDB |

## ภาคผนวก ค เกณฑ์ยอมรับผลลัพธ์

| ส่วน | เงื่อนไขผ่าน |
| :--- | :--- |
| ตัวตรวจจับ | ตรวจพบรถเฉพาะในขอบเขต ROI และส่ง payload ทุก 10 วินาที |
| payload | มี `student_id` ทุกก้อน และ `congestion_level` เป็นตัวเลขเสมอไม่มี null |
| MQTT | publish ขึ้น topic ที่กำหนดด้วย QoS 1 และไม่มีคำเตือนส่งไม่สำเร็จ |
| Telegraf | log ไม่มีบรรทัด `E!` และ line protocol มี tag กับ field ครบ |
| InfluxDB | query ได้ทั้ง measurement ข้อมูลจริงและ measurement ค่าพยากรณ์ |
| Kafka | topic มี message เพิ่มขึ้นตามเวลา |
| โมเดล | MAE ต่ำกว่าการเดาว่าอีก 5 นาทีเท่ากับตอนนี้ |
| Grafana | ทุก panel แสดงค่าล่าสุด และสีของระดับตรงกันทุก panel |
