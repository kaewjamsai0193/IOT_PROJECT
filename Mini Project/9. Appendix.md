# ภาคผนวก

## ภาคผนวก ก คำสั่งเริ่มระบบ

```bash
cd ~/Documents/IOT/IOT_PROJECT

docker compose up -d                        # Mosquitto + Telegraf
.venv/bin/python main.py longvideo.mov      # ตัวตรวจจับ
.venv/bin/python predict_consumer.py        # สาย ML อีกเทอร์มินัลหนึ่ง
.venv/bin/python train_model.py             # เทรนโมเดลใหม่เมื่อมีข้อมูลมากขึ้น
```

ถ้าแก้ `telegraf.conf` ต้องสั่ง `docker compose restart telegraf` เพราะไฟล์ถูก mount เป็น volume

## ภาคผนวก ข จุดตรวจสอบบริการ

| บริการ | ที่อยู่หรือคำสั่งตรวจสอบ |
| :--- | :--- |
| Mosquitto | `docker compose exec mosquitto mosquitto_sub -t 'traffic/6620301002' -v` |
| Telegraf | `docker compose logs -f telegraf` |
| Kafka UI | http://172.16.2.117:8080 |
| InfluxDB | http://172.16.2.117:8086 |
