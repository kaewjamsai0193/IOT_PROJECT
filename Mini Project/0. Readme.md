## ระบบนี้ทำอะไร

ตรวจจับรถจากกล้อง CCTV ด้วย YOLO ติดตามรถทีละคันด้วย ByteTrack เพื่อวัดความเร็ว
แล้วสรุปเป็นระดับความติดขัด 0-3 ทุก 10 วินาที

ข้อมูลส่งขึ้น MQTT แล้วแตกสองสาย สายหนึ่งเข้า InfluxDB ให้ Grafana แสดงผล
อีกสายเข้า Kafka ให้โมเดล ML พยากรณ์ล่วงหน้า 5 นาที แล้วเขียนกลับ InfluxDB ที่เดิม

จุดเด่นคือวัดรถติดจาก **ความเร็ว** ไม่ใช่จำนวนรถ เพราะรถ 15 คันวิ่งฉิวไม่ใช่รถติด
แต่รถ 12 คันจอดนิ่งคือรถติด

## สถาปัตยกรรม

![System Architecture Diagram](images/system_architecture.png)

*ภาพที่ 1 ผังระบบ กล่องน้ำเงินรันบนเครื่องเรา กล่องส้มอยู่บน Server*

| Layer | เครื่องมือ | หน้าที่ |
| :--- | :--- | :--- |
| Output & Presentation | Grafana | แสดงสถานะปัจจุบันและค่าพยากรณ์ |
| Data Pipeline | Mosquitto, Telegraf, Kafka, InfluxDB | ลำเลียงและจัดเก็บข้อมูล |
| ML & Logic | YOLO26s + ByteTrack, RandomForest | ตัดสินระดับและพยากรณ์ 5 นาที |
| Edge & Sensing | คลิป CCTV / RTSP, Python + PyTorch | อ่านเฟรมและส่ง payload |

## วิธีรัน

```bash
git clone https://github.com/kaewjamsai0193/IOT_PROJECT.git
cd IOT_PROJECT

python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env        # ใส่ INFLUX_TOKEN

docker compose up -d                        # Mosquitto + Telegraf
.venv/bin/python main.py longvideo.mov      # ตัวตรวจจับ
.venv/bin/python predict_consumer.py        # สาย ML
```

น้ำหนัก YOLO (`*.pt`) ไม่อยู่ใน repo ultralytics โหลดให้เองตอนรันครั้งแรก
ส่วน `.env` ไม่ขึ้น git เพราะ repo เป็น public
