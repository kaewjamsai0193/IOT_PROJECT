# ปัญหาที่พบและแนวทางแก้ไข

| ปัญหา | สาเหตุ | แนวทางแก้ไข |
| :--- | :--- | :--- |
| ส่งข้อมูลเข้า Kafka โดยตรงไม่ได้ | broker ประกาศ `advertised.listeners` เป็น `localhost:9092` เครื่องอื่นจึงเข้าไม่ถึง | ช่วงแรกอ้อมผ่าน VerneMQ กับ Kafka Connect เมื่อแก้เป็น IP จริงแล้วจึงส่งตรง |
| กราฟขาดเป็นท่อน | Telegraf ติด tag `host` ซึ่งใน container คือ container ID ที่เปลี่ยนทุกครั้ง | ตั้ง `omit_hostname = true` |
| `camera_id` และ `student_id` หายจากฐานข้อมูล | parser json ทิ้งค่า string ทุกตัวที่ไม่ได้ระบุ | ระบุใน `tag_keys` |
| ข้อมูลหายเงียบตอน Mosquitto ไม่ทำงาน | `publish()` ไม่โยน exception แต่คืน rc = 4 | เช็ก `info.rc` ทุกครั้งแล้วพิมพ์คำเตือน |
| ความเร็วพุ่งผิดตอนเล่นคลิปวนซ้ำ | ภาพกระโดดกลับต้นคลิป ระบบคิดว่ารถวิ่งข้ามจอในเฟรมเดียว | ล้าง track ทั้งหมดทุกครั้งที่วนกลับต้นคลิป |
| กราฟเทียบความแม่นอ่านผิด | ค่าพยากรณ์เขียนที่เวลาต้นทาง ไม่ใช่เวลาที่ทำนายถึง | เลื่อนเส้นพยากรณ์ด้วย `timeShift(duration: 5m)` |
