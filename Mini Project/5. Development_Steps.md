# ขั้นตอนการพัฒนา

| ขั้น | สิ่งที่ทำ |
| :--- | :--- |
| 1 | ตรวจจับรถด้วย YOLO ต่อ ByteTrack ให้รถมี ID วาดขอบเขตถนนบน `mapreal.png` แล้วเขียนสูตรวัดความเร็วและตัดสินระดับ |
| 2 | ส่ง payload ขึ้น Mosquitto ทุก 10 วินาที พร้อมเช็ก return code กันข้อมูลหายเงียบ |
| 3 | ตั้ง Telegraf ให้เขียนลง InfluxDB แก้เรื่อง tag ที่หาย ชื่อ measurement และ tag host ที่ทำให้กราฟขาด |
| 4 | ทำ Dashboard บน Grafana กำหนดชุดสีและ Range mapping ให้ทุก panel ใช้ชุดเดียวกัน |
| 5 | ให้ Telegraf ส่งเข้า Kafka โดยตรง และแปลง payload ให้แบนราบเหมือนฝั่ง MQTT |
| 6 | เทรน RandomForest จากประวัติใน InfluxDB ได้เป็น `model.joblib` |
| 7 | `predict_consumer.py` อ่าน Kafka แล้วเขียนค่าพยากรณ์กลับเข้า InfluxDB |
