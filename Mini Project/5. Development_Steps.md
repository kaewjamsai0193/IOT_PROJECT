# ขั้นตอนการพัฒนา

## เตรียมตัวตรวจจับและขอบเขตถนน

เริ่มจาก YOLO ตรวจจับรถบนคลิป CCTV แล้วต่อ ByteTrack เพื่อให้รถแต่ละคันมี ID
วาดขอบเขตถนนด้วยเส้นแดงลงบน `mapreal.png` แล้วให้โปรแกรมแปลงเป็น mask
จากนั้นเขียนสูตรวัดความเร็วและตัดสินระดับความติดขัด

## ส่งข้อมูลขึ้น MQTT

เพิ่มการ publish payload JSON ทุก 10 วินาทีขึ้น Mosquitto ในเครื่อง
พร้อมเช็ก return code เพื่อไม่ให้ข้อมูลหายเงียบตอน broker ไม่ทำงาน

## ต่อ Telegraf เข้า InfluxDB

ตั้ง `telegraf.conf` ให้ subscribe topic แล้วเขียนลง measurement `traffic_6620301002`
แก้เรื่อง tag ที่หาย ชื่อ measurement ที่ชนกับทั้งห้อง และ tag host ที่ทำให้กราฟขาด

## ทำ Dashboard บน Grafana

เขียน Flux query ของแต่ละ panel กำหนดชุดสีและ Range mapping ให้ทุก panel ใช้ชุดเดียวกัน

## ส่งข้อมูลเข้า Kafka

เดิมต้องส่ง MQTT ไป VerneMQ กลางแล้วให้ Kafka Connect ดึงเข้า Kafka
เมื่อ broker เปลี่ยน `advertised.listeners` เป็น IP จริงแล้ว เปลี่ยนมาให้ Telegraf
ส่งเข้า Kafka โดยตรง และแปลง payload ให้แบนราบเหมือนฝั่ง MQTT

## เทรนโมเดลพยากรณ์

`train_model.py` อ่านประวัติจาก InfluxDB สร้าง feature และ label ที่เวลา +5 นาที
เทรน RandomForest แล้วบันทึกเป็น `model.joblib`

## ทำนายแบบเรียลไทม์

`predict_consumer.py` อ่าน event จาก Kafka สะสมข้อมูล 5 นาทีเพื่อสร้าง feature
แล้วเขียนค่าพยากรณ์กลับเข้า measurement `traffic_prediction_6620301002`
